Генератор подписей

Заполни поля — подпись соберётся сама. Скопируй и вставь в свою почту.

Так увидят получатели

Куда вставить

nic.ru (RU-CENTER)
  1. Нажми Скопировать код HTML.
  2. Почта → Настройки → Подпись, переключи редактор в режим «Код».
  3. Вставь код и сохрани.
Outlook (компьютер и веб)
  1. Нажми Скопировать подпись.
  2. Компьютер: Файл → Параметры → Почта → Подписи. Веб и новый Outlook: Настройки → Учётные записи → Подписи.
  3. Создай подпись, вставь (Ctrl+V) и сохрани.
Gmail (в браузере)
  1. Нажми Скопировать подпись.
  2. Настройки (шестерёнка) → Все настройки → Общие → Подпись → Создать.
  3. Вставь, внизу страницы нажми «Сохранить изменения».
Mail.ru и VK WorkMail
  1. Нажми Скопировать подпись.
  2. Открой настройки почты в браузере → раздел с подписью.
  3. Вставь в поле подписи и сохрани. Если логотип не вставился — добавь его кнопкой «Картинка» по ссылке ниже.
iPhone и iPad (Почта)
  1. Открой эту страницу в Safari, нажми Скопировать подпись.
  2. Настройки → Приложения → Почта → Подпись (iOS 17 и старше: Настройки → Почта → Подпись).
  3. Вставь. Если оформление пропало — сразу встряхни телефон и нажми «Отменить».
Thunderbird (компьютер)
  1. Нажми Скопировать код HTML.
  2. ☰ → Настройки учётных записей → нужный ящик.
  3. Отметь «Использовать HTML» и вставь код в «Текст подписи».
Android (Gmail, Thunderbird)
  1. Нажми Скопировать текстом.
  2. Gmail → меню → Настройки → твой аккаунт → Подпись в мобильном приложении.
  3. Thunderbird: меню → Настройки → ящик → подпись. Вставь.
  4. На Android подпись только текстовая, без логотипа и цветов.
